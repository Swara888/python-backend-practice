# Python Backend Practice – 95+ Resume Ready

A **Python-only backend repository** showcasing file handling, data validation, API calls, and testing.  
Designed to demonstrate **clean code, modularity, error handling, and testing** – perfect for internship resumes.

---

## ✅ Modules

1. **file_handling.py** – Read/write files safely with error handling.  
2. **data_validation.py** – Validate email addresses and phone numbers.  
3. **api_call.py** – Fetch data from APIs with proper error handling.  
4. **demo.py** – Demonstrates usage of all modules.  
5. **tests/** – Pytest examples for all modules.

---

## 🏗️ Setup Instructions

### 1. Clone the repo
```bash
git clone https://github.com/Swara888/python-backend-practice.git
cd python-backend-practice
```
2. Create & activate virtual environment
```bash
python -m venv .venv
# Windows
.venv\Scripts\activate
# Mac/Linux
source .venv/bin/activate
```

3. Install requirements
```bash
pip install -r requirements.txt
```

5. Run demo
```bash
python demo.py
```

7. Run tests
```bash
pytest
```
